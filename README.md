Para garantizar un correcto funcionamiento del software, mover la carpeta de nombre "Proyecto" en C:\xampp\htdocs, o en el directorio donde se encuentra xampp/htdocs.
Dentro de la carpeta se encuentra otra carpeta llamada ProyectoSyntropy en la cual se encuentran todos los archivos de codigo, incluyendo el archivo syntropy.sql, el cual debe importar en localhost/phpmyadmin

En caso de al momento de importar el archivo syntropy.sql en localhost/phpmyadmin arrojar el error de "La tabla camion ya existe", eliminar la carpeta syntropy desde C:\xampp\mysql\data y volver a intentar importarla.

Link al repositorio de GitHub: https://github.com/EpsilonCore/ProyectoSyntropy
